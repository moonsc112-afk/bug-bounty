# Bug Bounty Skills

Kumpulan skill untuk perburuan bug, audit smart contract, validasi PoC, dan pelaporan. Disusun dari skill Hermes yang terpasang (`skills/`) plus arsip skill bug hunting (`cache/scratch/intel_digest/cb_all_skills`), deduplikasi dengan mengutamakan versi terpasang.

**121 skill**, **285 file** total. File pendukung (references, scripts, templates) ikut disalin;kecuali `__pycache__` dan `.pyc`.

## Struktur

- `BUG_BOUNTY_SKILLS.md` - satu file markdown berisi seluruh isi skill (versi baca-cepat).
- `skills/<kategori>/<nama>/SKILL.md` - skill per file, siap disalin ke direktori skill agen.
